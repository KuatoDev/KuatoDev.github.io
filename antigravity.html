Antigravity for Android

Native Android port of Google Antigravity Agentic IDE

verified v1.0.0 Release smartphone Android 11+ memory ARM64 (aarch64) code Jetpack Compose

Antigravity for Android runs Google Antigravity AI coding agents directly on Android devices. It provides a standalone ARM64 Linux userspace paired with a sleek, native Jetpack Compose UI — enabling autonomous AI agents to inspect your codebase, edit project files, and execute terminal commands (git, bash, python, pkg) on your smartphone without requiring a computer.

stars Key Features

  • check_circle Jetpack Compose UI: Modern, lightweight chat interface and mobile-tailored code viewer.
  • check_circle Local Linux Userspace: Full ARM64 environment with bash, python3, git, and dev utilities.
  • check_circle Official Agent Core: Powered by the Antigravity language_server authenticated via Google OAuth 2.0 PKCE.
  • check_circle Package Manager (pkg): Built-in terminal package manager for effortlessly installing developer tools.
  • check_circle Background Daemon (agy-daemon): Manages cron jobs, file watchers, and real-time push notifications.
  • check_circle Skills & Plugins Catalogue: Discover and load community extensions and skills directly from GitHub.

tune System Requirements

  • android Operating System: Android 11.0 or higher.
  • developer_board Architecture: 64-bit ARM (arm64-v8a).
  • folder_shared Permissions: Storage access (All Files Access) to manage local workspace repositories.
  • notifications Notifications: For background agent progress and task completion alerts.

  • extension antigravity-catalogue — Open skills and plugins catalogue open for community contributions.
